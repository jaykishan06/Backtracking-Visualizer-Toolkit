# Backtracking-Visualizer-Toolkit
Backtracking Visualizer Toolkit is a Python-based interactive tool to visualize and understand backtracking algorithms. It helps users explore the N-Queens and Subset Sum problems through step-by-step recursive simulations.  
💡 Features  
1.Visualizes backtracking for N-Queens and Subset Sum problems   
2.Step-by-step recursive decision-making process  
3.Great for learning recursion and algorithm design   

🚀 How to Run  
Save the script as backtracking_toolkit.py.  
Run the program using Python 3.x:  
python backtracking_toolkit.py  
Choose a problem and follow the prompts.  

📘 Educational Use  
This tool is ideal for:  
...Computer science students  
...Anyone learning recursion and backtracking algorithm
